# Code signing policy

Pilot is applying to the SignPath Foundation for a code signing certificate for its Windows releases. After approval, Windows releases signed through the program will carry this attribution.

> Free code signing provided by SignPath.io, certificate by SignPath Foundation.

[SignPath.io](https://about.signpath.io/) · [SignPath Foundation](https://signpath.org/)

Pilot builds its Windows installer from the public repository with GitHub Actions. The maintainer reviews changes and will manually approve each SignPath signing request for the corresponding release commit. [Build workflow](../.github/workflows/windows.yml) · [Releases](https://github.com/Murmureeee/Pilot/releases)

Murmureeee is the maintainer, committer, reviewer, and signing approver. [Maintainer](https://github.com/Murmureeee)

Pilot's privacy policy describes local storage and connections to user-configured services, websites, and the GitHub Releases update feed. [Privacy policy](./PRIVACY.md)
